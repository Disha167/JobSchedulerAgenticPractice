# PR #311: HTTP endpoint to submit jobs

**Author's description:** Adds `POST /jobs` so internal services can submit jobs over HTTP.
Also retries webhook notifications when a job finishes.

**Your task (15 minutes):** approve or request changes? Write comments from most to least
important, each with why it matters and a fix.

```java
@RestController
public class JobController {

    private static JobScheduler scheduler = SchedulerHolder.get();
    private static final Map<String, String> WEBHOOKS = new HashMap<>();

    @PostMapping("/jobs")
    public ResponseEntity<String> submit(@RequestBody SubmitRequest req) {
        log.info("Submitting job: " + req);   // req includes the caller's webhook auth token
        try {
            Job job = new Job(req.id, req.tenantId, req.priority, req.dependsOn, req.maxAttempts);
            scheduler.submit(job);
            WEBHOOKS.put(req.id, req.webhookUrl);
            return ResponseEntity.ok("submitted");
        } catch (Exception e) {
            return ResponseEntity.ok("error");
        }
    }

    public void onJobFinished(String jobId) {
        String url = WEBHOOKS.get(jobId);
        for (int i = 0; i < 10; i++) {
            try {
                http.post(url, "{\"job\":\"" + jobId + "\"}");
                return;
            } catch (Exception e) {
                Thread.sleep(1000);
            }
        }
    }
}

class SubmitRequest {
    public String id;
    public String tenantId;
    public int priority;
    public Set<String> dependsOn;
    public int maxAttempts;
    public String webhookUrl;
    public String webhookToken;
}
```
